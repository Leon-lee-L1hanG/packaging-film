# 连续装配镜头和声音

旧片20秒节奏是参考关系，不是不同产品都要照抄的时间表：

| 时间 | 画面意图 |
|---|---|
| 0–4.5s | 从纸卡槽口和金属表面近景建立真实触感，下层定位和轴件入槽 |
| 4.5–8.6s | 连续拉远看清下层整体及承托关系，隔板进入 |
| 8.6–12.8s | 上层定位和产品落位，保持关键信息无遮挡 |
| 13.55–16s | 围箱从画面外平稳下降到最终装配位置 |
| 16.25–17.2s | 天盖闭合 |
| 17.32–18s | 绑带依次收紧，与音效落点对应 |
| 18–20s | 完整包装留出约2秒清楚展示 |

新模型没有上层时删除相应阶段；只有一个产品模型且没有包装时，做同款材质产品展示或确认包装设计需求，不能擅自发明已批准的内衬。成品闭合模型若缺乏可分件结构，不能强行做穿模装配。

- 原片使用一个物理相机，36mm传感器；近景约72–78mm，远景约51–56mm，f/16，对焦目标随动作移动。新模型应按主体尺寸重定距离，避免广角畸变和过浅景深让槽口看不清。
- 位置、观察目标、焦距使用平滑Hermite/Catmull-Rom式连续插值；起止速度收敛。逐帧旋转四元数保持符号一致（相邻dot<0则取反）。检查插值过冲，不能只核对关键帧。
- 动画以最终正确装配姿态为基准，控制空物体把零件从安全方向带入，落位时回到原始矩阵。标识、微结构和纤维随所属零件运动。
- 在相机动画完成后，用world_to_camera_view检查入场前几帧所有包围盒角点；需要从画外出现的部件应确实在画外，不在视野中突然显示。必要时提高入场距离，并重查时间中段与其他零件的路径。
- motion blur shutter .35作为默认；快速入場允许合理拖影，但落位后标识必须清晰，不能把模糊当成贴图失败或把硬切当成顺滑。

## 声音

默认无旁白、无字幕，轻节奏BGM+短促装配音效。按动作事件生成cue表，每个落位事件记录时间和音效类型，避免密集冲击、刺耳沙噪、突然切断；主体入场可用短上升音，接触落位用轻木/纸/低频触点，金属入槽用柔和金属点音，封盖与绑带各有短落点。

同一旧片仅改标识：直接复制原音轨，不改变声音。同款新模型：音乐和SFX长度、事件重新适配；可本地合成，或使用用户已授权素材。不要把旧片音效时间表生搬到新的落位时间。默认48kHz立体声，留峰值余量，首尾短淡化。检查响度、削波、编码时间；实际试听和技术检查分开记录。
